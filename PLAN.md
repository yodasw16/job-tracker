# Product roadmap

## MVP

- Private email/password login and responsive opportunity tracking.
- Job details, original posting links, status grouping, and application-date sorting.
- Dated activity history, next actions, and inclusive date-range reporting.
- Reviewed spreadsheet import with duplicate protection, preserved source values, and explicit handling of unknown dates and ambiguous status mappings.
- Private hosted access, account recovery, backup procedure, and production verification.

The core tracker is implemented locally. Import and release readiness remain in progress. Import modeling should distinguish current status, interactions, final results, and notes without inventing historical events.

## Next milestone

Custom interview rounds, one preparation guide per round, combined guide view, CAR stories with optional Task and lessons fields, quick notes, pasted summaries, and direct navigation from scheduled interviews to preparation.

## Future ideas

Editable guide exports, job-post capture and reviewed autofill, reusable experience library, relevant-story suggestions, tailored guides, self-hosting documentation, and optional additional sign-in methods.

Offline editing and push/email reminders are outside the current scope.
